# 🪙 Bitcoin Application

A Python-based desktop application designed to interact with Bitcoin data metrics, track real-time price movements, and process transactional currency analytics.

## 🚀 Core Features
* **Live Price Tracking:** Pulls real-time Bitcoin data metrics.
* **Data Logging:** Cleans and structures data streams for analytical tracking.
* **Interactive UI:** Provides a user-friendly desk interface for continuous financial data monitoring.

## 🛠️ Tech Stack & Tools
* **Language:** Python
* **Environment:** Git / GitHub
* **Libraries:** Tkinter / CustomTkinter (Desktop UI integration)

## 📂 File Architecture
All core execution files, asset configurations, and logic scripts are maintained inside the primary module folder:
* `p1_btc_app/` - Contains the Python script execution layer, environment configurations, and dependency modules.
